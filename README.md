# Financial Sales Dashboard (Power BI)

An interactive Power BI dashboard that analyzes sales performance, profit trends
and units sold across products, months and countries.
![Financial Sales Dashboard](images/dashboard_preview.png)
## Project Objective
Help business stakeholders understand which products, months and regions drive
the most sales and profit.
## Key Insights
- **Paseo** is the top-selling product, contributing about 32% of total sales.
- **December and October** deliver the highest profit; January is the lowest.
- **October** has the highest units sold (~57K), while May is the lowest.
- Total profit across the period is **7.09M**.
- Sales are concentrated in **North America, Mexico and Europe**.
## Dashboard Visuals
| Visual | Purpose |
|---|---|
| Column chart: Profit by Month | Shows seasonal profit trends |
| Pie chart: Sales by Product | Shows product contribution to sales |
| Column chart: Units Sold by Month | Shows demand patterns |
| Donut chart: Total Profit | Highlights overall profit |
| Map: Sales by Country | Shows geographic distribution |
## Tools Used
- Microsoft Power BI Desktop
- Microsoft Excel
- DAX / Power Query
## Dataset
`data/Financial_Report.xlsx` includes Segment, Country, Product, Units Sold,
Sale Price, Gross Sales, Discounts, Sales, COGS, Profit, Date, Month and Year.
## How to Use
1. Download or clone this repository.
2. Open `dashboard/Financial_Report_Dashboard.pbix` in Power BI Desktop.
3. If prompted, point the data source to `data/Financial_Report.xlsx`.
